# 🚰 Sistema de Monitoramento de Reservatório de Água - Agenda 11

Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas (DS I) da Etec.

## 📌 Sobre o Projeto
Este script em Python simula o monitoramento contínuo dos níveis de água de um reservatório. O sistema exibe o status de cada nível com cores dinâmicas e personalizadas no terminal utilizando a biblioteca `colorama`.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Colorama** (Estilização de cores no terminal)
- **Git & GitHub**
